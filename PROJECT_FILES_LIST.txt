SMART ATTENDANCE SYSTEM - ALL PROJECT FILES
============================================

BACKEND FILES (Python/FastAPI):
-------------------------------
1. main.py - Main FastAPI application with all API endpoints
2. face_detector.py - YOLOv9 face detection (30+ FPS, 50+ faces)
3. face_recognizer.py - ArcFace recognition (512-D embeddings, >97% accuracy)
4. liveness_detector.py - Anti-spoofing detection (texture + depth analysis)
5. db_manager.py - PostgreSQL database manager with SQLAlchemy
6. faiss_index.py - FAISS vector similarity search manager
7. face_alignment.py - Face alignment and preprocessing utilities
8. preprocessing.py - Image preprocessing and enhancement
9. schemas.py - Pydantic models for API request/response
10. train_arcface.py - Training script for ArcFace on VGGFace2

FRONTEND FILES (React):
-----------------------
1. AttendanceCapture.jsx - Main attendance marking interface with webcam
2. UserRegistration.jsx - User registration with multi-image upload
3. package.json - Frontend dependencies and scripts

CONFIGURATION & DEPLOYMENT:
---------------------------
1. requirements.txt - Python dependencies (FastAPI, PyTorch, OpenCV, etc.)
2. docker-compose.yml - Docker deployment configuration
3. README.md - Complete project documentation
4. SETUP_GUIDE.md - Detailed installation and setup instructions
5. QUICKSTART.md - Quick 5-step startup guide

REQUIRED MODEL WEIGHTS (download separately):
---------------------------------------------
1. yolov9_face.pt - YOLOv9 face detector
   Source: https://github.com/WongKinYiu/yolov9

2. arcface_r100.pth - ArcFace recognizer
   Train with: train_arcface.py
   Or download: https://github.com/deepinsight/insightface

3. liveness_model.pth - Liveness detector
   Train your own or find pre-trained
   Source: https://github.com/minivision-ai

RECOMMENDED DATASET (for training):
-----------------------------------
VGGFace2: 3.31M images, 9,131 identities
Download: kaggle datasets download -d greatgamedota/vggface2-mini
